Neden?

Tek ajanla kodlamanın üç gizli maliyeti

En pahalı model her dosyayı okur, her adımı düşünür, tokenları yakar.
Şef araçsız çalışır, tur başına tek JSON yanıt verir; yalnızca odaklı repo haritası, ilgili bellek, diff ve kapı çıktısını görür.
5 saatlik ya da haftalık limit dolunca yarım iş çöpe gider.
Görev başka işçiye geçer; hepsi limitliyse kalıcı kuyrukta bekler ve sıfırlanınca aynı oturumda, aynı worktree’de devam eder.
Ajan ana dalınızda doğrudan değişiklik yapar.
Her görev kendi git worktree’sinde; kabul edilen iş --no-ff ile birleşir, reddedilen silinir.
Özellikler

Kalite kapılarıyla, az tokenla kodlama

Zaten ödediğiniz kodlama CLI’larını tek bir orkestrada birleştirir.

Şef + üç işçi

Şef hedefi en fazla 3 görevlik küçük bir plana böler; sıfır tokenlı yönlendirici kimin ne yapacağını puanlar.

Token tasarrufu

Şef dosya okumaz; işçiye ≤120 kelimelik özet gider; düzeltme kodu yazan işçiye döner; budget.maxTokensPerTask sınırı.

Varsayılan izolasyon

Her görev ~/.orkestra/worktrees/ altında kendi worktree’sinde çalışır.

Önce kapılar, sonra inceleme

npm test, cargo test, go test, pytest otomatik algılanır. Şef yalnızca kapı düşerse, diff boş/büyükse ya da testler zayıflatıldıysa uyanır.

Limit takibi ve otomatik devam

Claude statusline kancası, Codex günlükleri ve 429/“try again in…” taraması; limit sıfırlanınca aynı oturumda devam.

Kalıcı proje belleği

Markdown bellek bankası + SQLite FTS5 olgu deposu (yerleşik node:sqlite), token bütçesiyle enjekte edilir.

Repo haritası

12 dil için tree-sitter tanımları ve hedefe kişiselleştirilmiş PageRank sıralaması.

Her yerden kullanın

CLI · MCP sunucusu · VS Code eklentisi (@orkestra) · Windows, macOS ve Linux için Tauri masaüstü uygulaması.

Kurulum

Bir dakikada orkestrayı kurun

Gereksinimler: Node.js ≥ 22.16 (FTS5’li yerleşik node:sqlite), git ve giriş yapmış en az bir ajan CLI’ı.

# 1) Kullanmak istediğiniz ajan CLI’ları (herhangi bir alt küme)
npm i -g @anthropic-ai/claude-code @openai/codex @google/gemini-cli opencode-ai
# 2) Super Orkestra
npm i -g super-orkestra
super-orkestra --version
# 3) Projenizde (bir git deposu) çalıştırın
cd ~/code/my-project
super-orkestra run "add 2FA to the login page and write tests for it"

Yapılandırma dosyası gerekmez. Ücretsiz, girişsiz deneme: examples/free-opencode.config.json şef ve üç işçi için opencode’un ücretsiz modellerini kullanır.

Masaüstü uygulaması CLI’ı sürer; önce CLI’ı kurun.

SSS

Sık sorulan sorular

Ek bir abonelik ya da API anahtarı gerekiyor mu?
Hayır. İşçiler zaten giriş yaptığınız Claude Code, Codex, Gemini CLI ya da opencode’u kullanır. OpenRouter modelleri için yalnızca isterseniz API anahtarı eklersiniz; opencode’un ücretsiz modelleriyle girişsiz de denenebilir.
Birden çok hesabım arasında otomatik geçiş yapar mı?
Hayır. Sağlayıcıların kullanım koşullarıyla çelişebileceği için bu özellik bilinçli olarak uygulanmadı.
Proje git deposu değilse?
O zaman işçiler izolasyon olmadan doğrudan proje klasöründe çalışır. Tam izolasyon için depoda en az bir commit olmalı.
CLI çıktısı İngilizce mi?
CLI mesajları şu an Türkçe; İngilizce arayüz seçeneği yol haritasında. Belgeler İngilizce ve Türkçe.
Lisans nedir?
MIT. Ücretsiz, ticari kullanım dahil.
