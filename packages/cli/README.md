# super-orkestra

**Super Orkestra** CLI: en güçlü model şef olur (plan + denetim), altında seçtiğin 3 işçi model çalışır. Claude Code, Codex, Gemini CLI, opencode ve OpenRouter ile çalışır; en az token ve abonelik limiti harcayarak en kaliteli sonucu hedefler.

```bash
npm i -g super-orkestra
cd projen && super-orkestra run "login sayfasına 2FA ekle ve testlerini yaz"
```

`orkestra` kısa adı da aynı komuttur. Belgeler: https://github.com/cumabozkurt/super-orkestra#readme
