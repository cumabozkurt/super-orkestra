# super-orkestra-core

[Super Orkestra](https://github.com/cumabozkurt/super-orkestra) çekirdeği: şef/işçi yönlendirme, ACP ve headless CLI işçileri, izole git worktree'ler, test kapıları, kalıcı hafıza (markdown + SQLite FTS5), tree-sitter repo haritası, 5 saatlik/haftalık limit takibi ve otomatik devam, MCP sunucusu.

Çoğu kullanıcı doğrudan CLI'ı kurmalı: `npm i -g super-orkestra`.
