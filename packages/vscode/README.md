# Super Orkestra — VS Code

Şef model + 3 işçi model: en az token ve limitle en kaliteli kod.

1. Önce CLI'ı kur: `npm i -g super-orkestra`
2. Sohbette `@orkestra <görev>`; komutlar: `/limits`, `/usage`, `/recall`
3. Super Orkestra MCP sunucusu Copilot ve diğer MCP istemcilerine otomatik kaydolur; durum çubuğunda limit yüzdesi görünür.

Ayar: `orkestra.command` — CLI komutu veya tam yolu (varsayılan `orkestra`).
Belgeler: https://github.com/cumabozkurt/super-orkestra#readme
